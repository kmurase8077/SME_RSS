Synthesizable Molecular Explorer (SME) Tool Manual

This tool uses AiZynthFinder to search for synthesizable molecules with a similar molecular skeleton.

<Usage>
Activate the conda environment
# conda activate aizynth-env

Fill in the required information in sme_config_en.ini, then run the following:
# python synthesizable_molecular_explorer.py --ini sme_config.ini

<Outputs>
When you run the script, the following files will be output:

1. mutants_results.jsonl (* The name specified by 'out' in the ini file)
   For each ligand, the results (such as the score) of the "synthesizable molecule (original or mutant)" are sequentially output in JSONL format. The giant tree data has been excluded to keep the file lightweight.

2. sme_results/summary.csv
   A summary table for all ligands detailing whether the exploration was ultimately successful (is_solved), the number of synthetic steps, and other information.

3. sme_results/<ligand_name>/ folder
   If the exploration is successful, the actual synthetic route tree images proposed by AiZynthFinder (such as route000.png) will be saved here.

4. aizynth_runs/ folder
   The raw data (JSON files) generated when AiZynthFinder performs its exploration are saved here. You basically do not need to check these, but they can be used if you want to view the detailed analysis logs.

<sme_config_en.ini Settings>
Settings for batch or smiles, config, and jobs are mandatory.

[Execution]
# Single SMILES to analyze (leave empty if using batch processing)
smiles = 

# Input file path for analyzing multiple molecules (TSV format: name\tSMILES)
# (If 'smiles' above is specified, it takes priority)
batch = input_test.smi

# Path to AiZynthFinder config.yml
config = config.yml

# Maximum number of trials (number of mutants to generate)
samples = 100

# Maximum number of substitutions per molecule
max_swaps = 10

# Number of parallel CPU jobs (leave empty to automatically use half of maximum available. Approx 3 GB memory consumed per job)
jobs = 12

# Output file path for results (JSONL format)
out = mutants_results.jsonl

[Settings]
# Types of atoms allowed for substitution (comma-separated)
mutate_allowed = C, N, O, S, F, Cl, Br

# Probability weights for each atom selection (corresponds to the types above. comma-separated)
mutate_weights = 0.6, 0.2, 0.15, 0.02, 0.01, 0.01, 0.01

# Allowed range for C/N ratio (ratio of N to the sum of C and N)
min_n_ratio = 0.10
max_n_ratio = 0.30

[MaxCounts]
# Maximum allowed count of each atom in the generated mutants
S = 1
O = 4
F = 1
Cl = 1
Br = 1

[ProtectedSMARTS]
# SMARTS patterns for functional groups that should not be mutated
# The left side of '=' is a recognizable name, and the right side is the SMARTS notation
# Remove the '#' at the beginning of the line to enable the functional group you want to protect (in the example below, only the carboxyl group is enabled)
carboxyl = [CX3](=O)[OX2H1,OX1-]        # -COOH
# ketone = [#6][CX3](=O)[#6]            # -C=O
# hydroxyl = [OX2H]                     # -OH
# primary_amine = [NX3;H2;!$(NC=O)]     # -NH2
# secondary_amine = [NX3;H1;!$(NC=O)]   # -NHR
# tertiary_amine = [NX3;H0;!$(NC=O)]    # -NR2
# ester = [#6][CX3](=O)[OX2H0][#6]      # -COOR
# ether = [OD2]([#6])[#6]               # -OR
